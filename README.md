# Classroom Pro

Prototipo académico de rediseño de una plataforma educativa inspirado en Google Classroom.

## Cómo abrirlo en Visual Studio Code
1. Descarga y extrae `classroom-pro.zip`.
2. Abre Visual Studio Code.
3. Selecciona **Archivo > Abrir carpeta** y elige `classroom-pro`.
4. Abre `index.html`.
5. Puedes abrirlo directamente en el navegador o utilizar la extensión **Live Server** y pulsar **Go Live**.

## Cómo publicarlo gratis con GitHub Pages
1. Crea un repositorio público en GitHub llamado `classroom-pro`.
2. Sube los archivos `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En GitHub, entra en **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama **main** y la carpeta **/(root)**. Pulsa **Save**.
6. Espera unos minutos. GitHub mostrará el enlace público de tu sitio en esa misma sección.

## Funciones incluidas
- Panel de inicio y resumen académico.
- Navegación entre clases, tareas, calendario, mensajes y progreso.
- Marcar tareas como completadas y crear tareas de demostración.
- Calendario navegable.
- Mensajería de demostración.
- Asistente educativo con respuestas simuladas.
- Configuración de modo oscuro.
- Diseño adaptable a computadoras y teléfonos.

## Importante
Este proyecto es un **prototipo frontend**. Los nombres, asignaturas, mensajes, calificaciones y fechas son datos ficticios. No incluye cuentas reales, base de datos, envío real de mensajes ni conexión a un modelo de inteligencia artificial. No introduzcas contraseñas ni información personal.
